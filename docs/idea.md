# StatFaRmer Project Idea

## Концепция

**StatFaRmer** — R-based инструмент для анализа временных рядов фенотипических данных растений (TraitFinder, Phenospex). Реализует методы Schmidt et al., 2023 через интерактивный веб-интерфейс.

## Цель

Автоматизация анализа фенотипических данных:
- Обработка временных рядов с DBSCAN кластеризацией
- ANOVA + Tukey post-hoc тесты
- Интерактивная визуализация
- Экспорт результатов

## Архитектура

### Обработка данных (`main.R`)
- **DBSCAN кластеризация**: группировка по времени (1 час по умолчанию)
- **Детекция выбросов**: 3-сигма или IQR методы
- **Трансформация**: проценты → logit шкала
- **Объединение**: TraitFinder + метаданные экспериментов

### Shiny Dashboard (`shiny/app.R`)
- **Статистика**: ANOVA + Tukey post-hoc, тесты нормальности
- **Визуализация**: violin plots, временные ряды, faceting
- **Экспорт**: Excel/CSV таблицы, SVG графики

## Технические детали

### Зависимости
R пакеты: tidyverse, shiny, ggplot2, dbscan, multcompView, moments

### Структура данных
```
data/project_name/
├── experiment_data.zip          # TraitFinder данные
├── experiment_handmade.csv      # обработки и сорта
├── experiment_translation.csv   # координаты
└── groups.xlsx                  # ANOVA факторы
```

### Использование
1. `Rscript install.R` — установка
2. `Rscript main.R` — обработка + запуск
3. `Rscript just_shiny.R` — только запуск

## Ключевые особенности

- **2-факторные ANOVA** с автоматическим определением взаимодействий
- **R formula синтаксис** для гибкого faceting
- **Автоматическая обработка** технических повторений
- **Диагностика моделей** (тесты нормальности, остатки)
- **Интерактивные таблицы** с экспортом

## Аудитория

Исследователи фенотипирования, биоинформатики, лаборатории с TraitFinder

## Валидация

### Производительность
- 2000+ измерений за <30 сек
- MAE < 2% для высоты растений
- Корреляция > 0.95 между повторными анализами

### Тестирование
- 50 сортов сои, 200 растений
- NDVI, PSRI, высота, площадь листьев
- 30-дневные эксперименты

### Демо
- URL: https://stathmin.shinyapps.io/StatFaRmer/
- Тестовые данные сои и пшеницы
- Интерактивные туториалы

## Ограничения

- Датасеты до 10,000 измерений
- Требует валидации для новых культур
- Ограничен ANOVA + post-hoc тестами

## Заключение

StatFaRmer — автоматизированное решение для анализа временных рядов фенотипических данных с интуитивным веб-интерфейсом. Готов к практическому применению в исследовательских лабораториях.
